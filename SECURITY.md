# Security Policy

## Supported Versions

Only the latest release of PlugManReloaded receives active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in PlugManReloaded, please **do not** open a public issue on GitHub.

Instead, please report the vulnerability privately via [GitHub Private Vulnerability Reporting](https://github.com/MilkyWayTop16/PlugManReloaded/security/advisories/new).

Please include:
* Description of the vulnerability and its potential impact.
* Server platform and version (e.g. Paper 1.20.4, Purpur 1.21).
* Steps to reproduce or proof-of-concept exploit.

We take security seriously and will investigate and address reported issues promptly.
